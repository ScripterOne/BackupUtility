Consolidator — disk health

Which drives can be trusted with the only copy of something.
UNKNOWN is not OK. Most large drives here sit behind a USB‑SATA bridge, and both of the usual SMART paths return nothing rather than an error on USB — which reads like good news. This tool tries an explicit chain of device types (-d sat, usbasm1352r, usbjmicron…), reports which one answered, and says UNKNOWN when none did.
UDMA CRC errors mean the cable or bridge, not the platter — the drive is probably fine and the path to it is not. That is the likeliest fault on this estate.
